# SillyClient iOS v1.14.3 (Build 48)

> 紧急修复 iOS 文件夹与文件选择全链路故障：解决选择器下拉关闭后后续选择永久锁死、外置 Files / iCloud 目录 bookmark 失效或陈旧拒用、非安装类选择缺少文件协调以及前端误吞错误等问题。本版仅更新 iOS，继续跳过 Windows 与 Android（后续统一整合）。

---

## 🛠️ 紧急修复内容（基于 Build 47 续查根治）

1. **修复选择器弹窗手势关闭导致后续所有选择锁死**：
   - `TarvenEnvPlugin` 实现 `UIAdaptivePresentationControllerDelegate` 并绑定 `picker.presentationController?.delegate = self`，用户在 `.formSheet` 下滑手势或点击外部取消时正确触发取消清理并返回 `PICKER_CANCELLED`；
   - 增加退场过渡重试与孤立回调回收，避免出现 `"Another picker is active or the presenter is unavailable"` 永久卡死。
2. **修复外置目录 Bookmark 易失与 Stale 拒用问题**：
   - `IOSInstallationLocations` 将 bookmark 创建选项由 `.minimalBookmark` 改为 `[]`，`coordinateRead` 使用 `.withoutChanges`；
   - 在 `select(_:)` 的协调读取作用域内完成 bookmark 生成（优先 picker URL，失败回退协调 URL）；
   - `acquire(_:grantId:)` 遇到 `stale == true` 且 `startScope` 成功、目录身份 `identity` 校验一致时自动刷新持久化 bookmark 并放行（权限彻底丢失或目录被替换仍 fail-closed 拒绝）；
   - `requireLocalRuntime(_:)` 写入能力探针改为包裹在 `NSFileCoordinator(filePresenter: nil).coordinate(writingItemAt:options:.forReplacing)` 内执行，返回清晰的系统域/码诊断信息。
3. **补全其余选择器协调与陈旧设置清理**：
   - 源目录 `dir`、导入压缩包 `zip`、封面 `image` 与文本读取 `readText` 回调统一接入 `NSFileCoordinator` `.withoutChanges` 读取协调与主队列回调；
   - 外置源目录安全作用域队列改为 FIFO 淘汰（上限 8 个，避免超过 8 次后永久拒选）；无扩展名封面图默认回退 `.png`；
   - `getAppSettings()` 核验并自动清理已失效的 `configuredInstancesRoot`。
4. **前端取消判定纠偏与中文报错诊断**：
   - `RelocateInstanceModal` 改用 `shouldShowDirectoryPickerError(error, isIOS)`，不再把包含 `cancel` 的 Files provider 系统错误当成用户取消静默忽略；
   - 首页安装目录选择与封面选择统一接入 `humanizeNativeError`，补全 iCloud 未下载、`ENOTSUP`、bookmark 丢失、系统容器拒绝等中文提示。
