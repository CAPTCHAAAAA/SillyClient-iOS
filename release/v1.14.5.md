# SillyClient iOS v1.14.5 (Build 50)

> 紧急修复 `v1.14.4`（Build `49`）真机实测暴露的目录选择静默丢弃与误报故障：移除覆盖系统文件选择器内部代理的 `presentationController?.delegate = self` 与 `.formSheet` 强制设置，加装非侵入式分离检测定时器消除静默取消假象；同时清理重复插件注册配置，前置拦截「我的 iPhone ▸ ...」等非路径粘贴文本并补全中文错误提示。本版仍仅更新 iOS，继续跳过 Windows 与 Android。

---

## 🛠️ 修复内容（基于真机录屏排查）

1. **移除系统文件选择器 presentation delegate 竞争并增加异常退出兜底**：
   - 真机录屏复现点击「文件」右上角「打开」后弹窗收起但输入框仍为空、界面无任何报错：`v1.14.3`–`v1.14.4` 为捕获下拉关闭而强制设置 `picker.modalPresentationStyle = .formSheet` 与 `picker.presentationController?.delegate = self`，会覆盖 `UIDocumentPickerViewController` 内部自适应代理或在远程 XPC 收尾时触发 `presentationControllerDidDismiss(_:)` 返回 `PICKER_CANCELLED`（前端按取消静默忽略）。
   - `TarvenEnvPlugin.swift` 现已移除 `UIAdaptivePresentationControllerDelegate`、`presentationController?.delegate = self` 与 `.formSheet` 覆盖，恢复 `.automatic` 默认呈现方式；并新增主队列轻量级 `DispatchSourceTimer` 监听（`startPickerDismissMonitor(for:call:)`，分离确认窗口 `>= 0.5s`），若选择器确未回调结果/取消便已退出，明确拒绝并返回 `PICKER_DISMISSED_WITHOUT_RESULT`，并在关键生命周期补充 `NSLog`。
2. **清理重复 Capacitor 插件注册**：
   - 移除 `AppDelegate.swift` 中在 `autoRegisterPlugins` 下已空转的 `registerPluginType:` 调用，并将 `capacitor.config.json`、`web/capacitor-ui/capacitor.config.json` 与 `build-ipa.yml` 中的 `packageClassList` 统一收敛为 `["TarvenEnvPlugin"]`。
3. **前置拦截非路径输入并补充通俗中文错误翻译**：
   - `install-location.ts` 新增 `validateInstallPathInput(rawValue, { isIOS })`，在进入安装/迁移流程前直接拦截 `我的 iPhone ▸ SillyClient` 等面包屑显示文字、相对路径、`..` 跳转和 URL 链接，避免进入启动弹窗后暴露底层英文报错；
   - `routes/index.tsx` 与 `RelocateInstanceModal.tsx` 接入该前置校验，`native-errors.ts` 新增 `PICKER_DISMISSED_WITHOUT_RESULT`、`An absolute local installation path is required` 等报错的通俗中文引导提示。
