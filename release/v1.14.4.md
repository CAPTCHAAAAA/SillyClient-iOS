# SillyClient iOS v1.14.4 (Build 49)

> 紧急修复 `v1.14.3` 上线后“部分用户已正常、部分机型/名称仍失败”的剩余断点：恢复 iOS 实例安全目录 ID 归一化并接入同步安全作用域获取，避免中文/默认名称建实例失败及外置目录选择器返回瞬间权限被收回。本版仅更新 iOS，继续跳过 Windows 与 Android（后续统一整合）。

---

## 🛠️ 修复内容（基于 Build 48 续查）

1. **修复留空、中文或含空格实例名创建实例时原生 ID 校验失败**：
   - `web/capacitor-ui/src/routes/index.tsx` 恢复 iOS 分支使用 `normalizeInstanceIdentity(...)` 并在重名后缀使用 `-${counter++}`，确保传入原生层的 `instanceId` 严格符合 `^[A-Za-z0-9_-]{1,128}$`，不再把中文（如默认「新实例」）或带空格括号的名称直接传入 `IOSInstanceStore.identity(_:)` 触发 `An explicit valid instance identity is required`；同时前端展示名称保持用户输入。
2. **消除文件选择器返回与异步文件协调之间的安全作用域竞争**：
   - `TarvenEnvPlugin.swift` 在 `documentPicker(_:didPickDocumentsAt:)` 返回给 UIKit 之前同步调用 `selected.startAccessingSecurityScopedResource()`（`preScoped`），确保在远程 picker XPC 销毁前锁定临时授权，随后在 `io.async` 内完成协调读取与书签生成并按分支对称释放或移交 `rememberScopedDirectory`。
3. **修正文件窗 Presentation 设置顺序与默认入口目录**：
   - 在 `presentPicker` 中先设置 `picker.modalPresentationStyle = .formSheet` 再绑定 `picker.presentationController?.delegate = self`；
   - 仅 `action == "installDir"` 设定初始 `picker.directoryURL`，不再强制封面、ZIP 与文本文件选择器固定进入应用沙盒 `Documents`。
4. **错误提示补全与统一**：
   - `native-errors.ts` 新增 `An explicit valid instance identity is required` 的中文映射，并在实例创建、启动与迁移选择器错误出口统一调用 `humanizeNativeError(...)`。
