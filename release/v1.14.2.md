# SillyClient iOS v1.14.2 (Build 47)

> 修复 iOS 新建实例安装目录授权恢复：Files bookmark URL 与文件协调器提供的实际访问路径可能不同，Build 47 在恢复授权时重新协调目录、验证原目录身份，并将实例路径映射到当前访问路径。真实 iPhone 的 Files provider 仍需安装本 Build 复测；严格守护 NodeMobile 嵌入式底座与 Documents 安全沙盒隔离。

---

## 🌟 核心特性与架构亮点

1. **新建实例安装目录选择与路径回填修复（核心修复）**：
   - **文件夹确认与外部授权修复**：原生文件夹选择器使用 `asCopy: false`；Files 外部目录选择阶段只保存 security-scoped bookmark 并回填路径，能力探针延迟到真正创建实例时，避免 provider 在选择回调中拒绝写协调；
   - **Files 授权恢复路径映射**：bookmark 恢复后重新通过 `NSFileCoordinator` 取得当前 accessor URL，核对目录身份，再将实例相对路径映射到 accessor 根；实例记录保留授权相对路径以支持后续 provider URL 变化，不再因路径字符串不同而拒绝使用，也不会接受被替换成其他目录的授权；
   - **iCloud 本地状态判断**：只拒绝明确标记为尚未下载的 iCloud 目录；已下载目录继续接受实际读写能力探针，不再将所有 iCloud 项目误判成纯云端；
   - **向导 iOS 身份透传**：向导组件完整注入 `isIOS` 状态标识，恢复原生系统文件选择器操作引导（“进入目标文件夹后点击右上角「打开」确认”）；
   - **精确与根目录模式智能判定**：完整支持 `root/exact` 目录模式，Documents 实例根预填和用户选择的新目录均按父目录安全建立实例子文件夹，手动编辑路径自动切换为精确路径，消除路径冲突；
   - **屏蔽不支持的 ZIP 运行时入口**：新建向导精准隐藏 iOS 平台不支持的本地运行时 ZIP 安装按钮，引导用户通过「实例管理 ➔ 存储路径」进行安全数据迁移；
   - **全链路一致性保障**：目录选择回填、实例创建、持久化注册与启动调用保持同一 `root/exact` 路径契约；主分支 CI 的静态检查、Release archive/IPA 与 hosted simulator E2E 均已通过，真机 Files provider 结果以 Build 44 安装复测为准。

2. **交互式聚光灯新手引导与视口级 SVG Mask 硬件级防撕裂**：
   - **彻底下线旧版迁移弹窗**：升级为全沉浸式 22 步隔离实战引导（`OnboardingSession`），在隔离沙箱环境中安全体验实例配置、背景交互与启动演练；
   - **视口级 SVG Mask 硬件镂空遮罩**：彻底消除高刷新率（120Hz/144Hz ProMotion）屏幕下的画面撕裂与白块频闪。摒弃传统 CSS `box-shadow: 150vmax` 引发的高达 8000×8000px（约 288MB 显存）的巨额离屏脏矩形重绘，改用视口受限矢量遮罩（`<svg><mask id="sc-spotlight-mask">`），将逐帧光栅化耗时降低 99.6%；
   - **沙箱平滑交错淡入淡出（Cross-fade）与背景交互锁**：沙箱就绪时采用多阶段透明度渐变过渡，消除页面切换白屏黑块竞态；引导与模态弹窗开启期间引入全局背景交互锁，杜绝滑动穿透与误触。

3. **卡片标题就地双向内联重命名与抽屉式控制台**：
   - 实例卡片未运行状态支持直接在标题位置双向内联编辑重命名（`InstanceRenameField`），双向平滑过渡，彻底下线独立弹窗 `RenameModal`；
   - 引入规范化抽屉组件 `InstanceCardDrawer`，普通卡与运行卡共用展开收起逻辑，支持多端手势与折叠动画；规范卡片与控制台操作按钮（`ActionButton`）。

4. **SC Bordeaux（波尔多红酒）主题预设升级（Revision 3 终态）**：
   - 内置主题预设升级至终态 Revision 3，高斯模糊半径调谐至 `14`，呈现更深邃通透的深红宝石液态玻璃质感与高可读性文字对比度。

5. **管理面板竖屏自适应与软键盘联动**：
   - 同步 `ToggleSwitch` 拨杆、字号梯级排版、`is-stacked` 项目排列；
   - 软键盘弹起时自动响应 Visual Viewport 动态自适应高度，避免遮挡关键配置与按钮。

6. **NodeMobile 嵌入式底座与安全沙盒守护**：
   - 原生进程级内置 `NodeMobile.xcframework` 与完整的 SillyTavern 核心服务代码，零依赖越狱或外部 Linux 容器，支持完全离线运行；
   - 严格守卫 UIDocumentPicker 文件夹选择指引与沙盒隔离保护，遵循 iOS 存储安全规范；
   - 实例管理 Storage 页签原生支持数据 ZIP 导入预检，局域网描述严格使用跨平台移动端建议文案；
   - 原生终端提示符严格对齐 `iOS 控制台` 与 `ios >`，支持 `status`、`gc` 等原生交互指令，无 Android 违和文案。

7. **变色龙 0 色差智能取色与硬件级灵动岛避让**：
   - 原生 4-bit 量化直方图众数聚类算法，毫秒级侦测酒馆主题背景色并渲染至原生顶条带；
   - 硬件级避让灵动岛（Dynamic Island）挖孔，实测接缝色差 $\Delta E = 0.00$；
   - 沉浸态自动隐藏底部小白条（Home Indicator）。

## 📲 安装与侧载指引（无需越狱）

本安装包为标准未签名 `.ipa`（Build 47 由 GitHub Actions macOS-15 官方 Xcode 编译封包），可通过以下任意方式安装：

### 方式 1：电脑端签名安装（推荐首选，零成本，最稳定）
使用任意日常个人免费 Apple ID（无需付费开发者账号）：
1. 电脑端下载并打开 **爱思助手**（Windows 一键 IPA 签名）或 **Sideloadly** / **AltStore**；
2. 将下载的 `SillyClient-iOS-v1.14.2-unsigned.ipa` 拖入签名工具；
3. 输入您的 Apple ID 进行本地签名并安装到 iPhone / iPad；
4. 手机打开【设置 ➔ 通用 ➔ VPN 与设备管理】信任开发者证书；
5. iOS 16 及以上打开【设置 ➔ 隐私与安全性 ➔ 开启开发者模式】并重启设备即可打开。

### 方式 2：手机端万能签 / 全能签 / 轻松签 / Scarlet
1. 手机端签名器导入有效的个人证书或企业测试证书；
2. 导入本 IPA 安装包，点击“签名”并确认安装即可。

### 方式 3：TrollStore（巨魔商店，iOS 14.0 ~ 17.0）
- 若设备已安装 TrollStore，直接将本 IPA 发送到设备点击“使用 TrollStore 安装”，**永久免证书、永不掉签**。
